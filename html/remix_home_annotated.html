Deployment Options

Three Ways to Deploy Remix

Choose your architecture based on your needs—from standalone apps to data lake-native experiences

1

Standalone Deployment

Build experiences that connect to any data source via APIs. Perfect for quick wins and getting started without infrastructure dependencies.

  • Connect to any API or data source
  • Deploy mobile, desktop, browser instantly
  • No data lake infrastructure required
Best for: Quick proof of value, testing use cases, personal apps
2

Data Lake-Native (Snowpark)

Run applications entirely inside Snowflake using Snowpark Container Services. Zero data movement, maximum security and performance.

  • Native Snowpark Container deployment
  • Zero data egress, full governance
  • Heavy analytics and compute workloads
  • Available in Snowflake Marketplace
  • Enterprise-grade security
Best for: Compliance-critical apps, analytics at scale, enterprise workloads
3

Augmented with Data Lake Context

External experiences enriched with unified context from your data lake. Best user experience combined with complete business data.

  • OAuth access to Snowflake for context
  • Enhance existing tools (Zendesk, HubSpot)
  • Mobile widgets with unified data
  • Build from phone in 60 seconds
Best for: Augmenting existing tools, mobile-first experiences, customer 360
